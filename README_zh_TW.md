# 惜物 Xiwu 📦

[简体中文](README.md) | [繁體中文](README_zh_TW.md) | [English](README_en.md) | [日本語](README_ja.md)

> **萬物皆有成本，認清真實消費。珍惜物品，物盡其用。**

「惜物」是一款個人資產折舊管理工具，幫助你追蹤消費品的折舊情況，計算物品的 **日均使用成本**，讓每一筆消費都清晰可見。

## ✨ 功能特色

- 📱 **資產錄入與管理** — 快速添加你的物品，記錄買入價格、日期和分類
- 📊 **總資產看板** — 一眼查看總資產殘值、總投入本金和總折損
- 📉 **三種折舊模型** — 根據物品類型自動計算殘值變化
- 💰 **日均使用成本** — 實時計算每件物品每天花了你多少錢
- 🎯 **物品生命週期** — 支援「服役中」和「已出掉/轉賣」兩種狀態
- 🎨 **手帳風設計** — 馬卡龍配色 + Emoji 圖標 + 趣味文案，讓記帳不再枯燥

## 🧮 折舊模型說明

| 模型 | 名稱 | 計算邏輯 | 適用場景 |
|:---|:---|:---|:---|
| 模型 A | 直線歸零法 | 設定預期使用壽命，價值每天平均遞減至 0 | 權益、消耗品（年卡、跑鞋等） |
| 模型 B | 落地打折 + 持續貶值 | 購買即扣 20% 價值，之後每年再按 15% 貶值 | 數碼產品、汽車等 |
| 模型 C | 保值/緩慢折舊法 | 設定保底殘值（50%），前期緩慢折舊至保底後不再下跌 | 奢侈品、貴金屬、高端家具 |

**核心公式：**
```
日均使用成本 = (買入價格 - 當前殘值) ÷ 已持有天數
```
