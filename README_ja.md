# 惜物 Xiwu 📦

[简体中文](README.md) | [繁體中文](README_zh_TW.md) | [English](README_en.md) | [日本語](README_ja.md)

> **すべてのものにはコストがあります。本当の消費を認識し、物を大切にしましょう。**

「Xiwu」は、個人の資産の減価償却を管理するツールです。消費財の減価償却を追跡し、アイテムの**1日あたりの平均コスト**を計算し、すべての出費を明確にします。

## ✨ 機能

- 📱 **資産の登録と管理** — アイテムをすばやく追加し、購入価格、日付、カテゴリを記録
- 📊 **総資産ダッシュボード** — 総資産の残存価値、総投資額、総減価償却額を一目で確認
- 📉 **3つの減価償却モデル** — アイテムの種類に基づいて残存価値の変化を自動的に計算
- 💰 **1日あたりの平均コスト** — 各アイテムが1日にいくらかかっているかをリアルタイムで計算
- 🎯 **アイテムのライフサイクル** — 「使用中」と「売却済/引退」のステータスをサポート
- 🎨 **美しいデザイン** — マカロンカラーパレット + 絵文字アイコン + 楽しいコピー

## 🧮 減価償却モデル

| モデル | 名前 | ロジック | シナリオ |
|:---|:---|:---|:---|
| モデル A | 直線ゼロ化 | 予想寿命を設定し、価値は直線的に0に減少 | 消耗品、メンバーシップ |
| モデル B | 落下と減衰 | 購入時に20％低下、その後年間15％減衰 | 電子機器、車 |
| モデル C | 価値維持/ゆっくり減価 | 最小残存価値（50％など）を設定し、最小値までゆっくりと減価 | 高級品、貴金属 |

**コア計算式:**
```
1日あたりの平均コスト = (購入価格 - 現在の残存価値) ÷ 所有日数
```
